NBA Shot Quality & Impact Model

I built a model that scores how hard every NBA shot is (xShot), then used it to rate each player by the quality of shots their lineups create and allow (xRAPM), with luck stripped out.

1 · Who makes their team better?

 

xRAPM is a player's estimated effect on his team's scoring margin per 100 possessions. It's measured from the quality of shots created and allowed while he's on the floor, after accounting for every teammate and opponent. 0 is average. +2 is a very good starter.

How this works

Data

Play-by-play for every regular-season and playoff game from 2014-15 to 2025-26, pulled from the NBA Stats API (nba_api) into PostgreSQL: about 7.5M events and 2.68M field-goal attempts with location, shot type and game clock.

xShot: how hard is this shot?

An XGBoost classifier predicts the probability a shot goes in using only what's known before the shot: location (distance, angle, zone, corner three), shot type (dunk, layup, pull-up, step-back, floater… 17 flags) and context (period, clock, overtime, playoffs). It does not know who is shooting, so it measures difficulty, not shooter skill, the same idea as expected goals (xG) in soccer.

Trained on 2014-15 → 2022-23 and tested on 2023-24 → 2024-25 (time-based split, so it never sees the future). Test log loss is 0.638 vs. 0.691 for predicting league-average FG% on every shot (7.7% better), with a Brier score of 0.225.

Shot-making vs. expected

For each player, actual FG% minus the average xShot of his attempts. Positive means he converts more than an average shooter would on the same shots. Players need 300+ attempts in a regular season (75+ in the playoffs) to be shown.

RAPM and xRAPM

The game is split into 422K stints, stretches where the same ten players are on the floor. A ridge regression then estimates each player's effect on the scoring margin per 100 possessions while controlling for everyone else on the court.

  • RAPM uses the points actually scored.
  • xRAPM replaces made/missed shots with their xShot value, which removes shooting variance and keeps the process: did the lineup create good shots and force bad ones?
  • 3-season ratings pool three years of stints. That cuts noise by about 40% compared with single seasons, so it's the default.

Limitations

xShot has no tracking data (defender distance, shooter speed), so "difficulty" is location- and play-type-based. xRAPM only sees field goals, not turnovers or free-throw trips. Ridge shrinkage pulls everyone toward 0, so the ratings here run a little smaller than public RAPM sites. Treat small differences as ties.
